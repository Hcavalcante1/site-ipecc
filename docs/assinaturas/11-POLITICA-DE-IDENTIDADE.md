# 11 — Política de identidade

## Estados
NOT_VERIFIED · PENDING · VERIFIED · SUSPENDED · REVOKED · EXPIRED

## Níveis
- BASIC — e-mail verificado + cadastro interno  
- VERIFIED — CPF (hash) + vínculo/aprovação  
- HIGH — preparado; biometria/prova de vida/certificado **não** obrigatórios nesta fase  

## Regras
Conta não compartilhada; suspenso/revogado não assina avançada; CPF só hash + last4 no cadastro; alterações críticas exigem revisão da habilitação.

## Limite
Habilitação interna IPECC ≠ verificação gov.br / ICP-Brasil.
