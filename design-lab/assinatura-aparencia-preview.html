  • Sem quadrado/borda colorida

  • Texto preto — modo Description (iText / Adobe)
  • Só: nome do certificado + data (ETSI TS 102 778-6)
Fontes (não só Adobe):
  • ETSI TS 102 778-6 — Visual Representations of Electronic Signatures (nome do signatário do certificado; aparência = texto/identidade do cert)
  • iText Knowledge Base — Part IV Appearances — layout Description only: “Digitally signed by” + nome + Date (texto preto no retângulo do campo)
  • ISO 32000-1 §12.8 — Signature appearance via annotation Rect; sem exigir caixa azul
  • DocuSign / leitores: a “chrome/frame” colorida é opcional e muitos usuários pedem para remover — assinatura profissional = sem moldura inventada
